# Which Spelling Is Correct?

## INTRO
Welcome to the English Quiz Challenge. Today, a spelling test. Each question shows the same word spelled in different ways. Only one is correct.
English spelling is famous for being difficult, so each answer comes with a small memory trick. You have five seconds for each question. Keep your score. Let's go!

## QUIZ | Questions 1 to 10
@ q Which spelling is correct? | neccessary | *necessary | necesary
Necessary: one C and two S's. Memory trick: one collar, two sleeves, like a shirt.
@ q Which spelling is correct? | seperate | *separate | separete
Separate. There's "a rat" in sep-a-rate.
@ q Which spelling is correct? | *definitely | definately | definitly
Definitely. It comes from the word finite, F-I-N-I-T-E. No A anywhere.
@ q Which spelling is correct? | recieve | *receive | receeve
Receive. The rule: I before E, except after C. So: R-E-C-E-I-V-E.
@ q Which spelling is correct? | *business | buisness | bussiness
Business. Think "busy-ness": B-U-S-I-N-E-S-S.
@ q Which spelling is correct? | tommorow | tomorow | *tomorrow
Tomorrow: one M, two R's.
@ q Which spelling is correct? | *beginning | begining | beggining
Beginning: one G at the start, then double N before I-N-G.
@ q Which spelling is correct? | accomodation | *accommodation | acommodation
Accommodation: double C and double M. It's a big word, so it needs lots of room!
@ q Which spelling is correct? | *Wednesday | Wensday | Wednsday
Wednesday. We say "Wenz-day", but we write W-E-D-N-E-S-D-A-Y. Say "Wed-nes-day" in your head when you write it.
@ q Which spelling is correct? | goverment | *government | govenment
Government. It comes from govern, plus M-E-N-T. Don't forget the N.

## QUIZ | Questions 11 to 20
@ q Which spelling is correct? | *believe | beleive | belive
Believe. Trick: never believe a lie. There's a "lie" inside believe.
@ q Which spelling is correct? | adress | *address | addres
Address: double D and double S.
@ q Which spelling is correct? | *library | libary | librery
Library. Many people say "libary", but there are two R's: L-I-B-R-A-R-Y.
@ q Which spelling is correct? | embarassed | embarrased | *embarrassed
Embarrassed: double R and double S. You go really red and smile shyly.
@ q Which spelling is correct? | *occasionally | ocassionally | occasionaly
Occasionally: double C, one S, double L.
@ q Which spelling is correct? | calender | *calendar | calandar
Calendar ends in A-R, like "year".
@ q Which spelling is correct? | *restaurant | restaurent | resturant
Restaurant: R-E-S-T-A-U-R-A-N-T. "Rest", then "au", then "rant".
@ q Which spelling is correct? | knowlege | *knowledge | knowladge
Knowledge: know, plus ledge. Two silent letters: the K and the D.
@ q Which spelling is correct? | *February | Febuary | Februery
February. Many people forget the first R: F-E-B-R-U-A-R-Y.
@ q Which spelling is correct? | untill | *until | untile
Until has only one L. But "till" has two!
