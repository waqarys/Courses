### Scene 1 – Hello, World (0:00–0:20)
**On-screen text:** "Your first program!"

Hi friends! I'm Minty the Python. Today you will write your very first computer program. It is just one line long! [pause] Is Thonny open on your computer? If not, ask a grown-up to help you install it, then come back.

### Scene 2 – print talks to the screen (0:20–0:45)
**On-screen text:** "print shows words on the screen"

In Python, the word print means: show this on the screen. The words you want to show go inside quotes, like a little speech bubble. And a line that starts with a hash sign is a note for people. Python skips it.

### Scene 3 – Smoke test (0:45–1:05)
**On-screen text:** "Smoke test: does it run?"

Our first program is a smoke test. It is like turning the key in a car. We are not driving across the city. We just ask: does it start? Does it say Hello, World? Let's try it together!

### Scene 4 – Capitals matter (1:05–1:25)
**On-screen text:** "Capitals matter!"

Here is a secret. Python is very fussy about capital letters. Small print and big Print are not the same word to Python. Watch what happens when we get it wrong, and how we fix it.

### Scene 5 – Two lines, in order (1:25–1:45)
**On-screen text:** "Line 1, then line 2"

Now let's write two lines. Python reads them from top to bottom, one after another. Line one finishes, then line two starts. That has a special name: sequence.
