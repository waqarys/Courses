## Description
A transformer block is a two-step study routine repeated 12 times: discuss with classmates (attention), then think alone (feed-forward) — with notes kept in the margin (residual) and a calm-down breath before each step (LayerNorm).

In this module of *Zero to LLM* we build it ourselves in plain Python and PyTorch — every line explained.
