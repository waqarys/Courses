## Description
Attention is a group chat where every word posts a question (query), wears a name-tag (key) and carries a message (value). Each word reads the messages of the words whose name-tags best match its question.

In this module of *Zero to LLM* we build it ourselves in plain Python and PyTorch — every line explained.
