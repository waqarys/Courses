## Description

Part II begins: from theory to code. We run GPT-2 in a few lines, learn the Python an LLM builder needs (strings, slicing, f-strings, lists, dictionaries, control flow, functions and classes), and build a working word-level tokenizer — SimpleTokenizer — shaped like Hugging Face's. Includes the real outputs from running the book's ch05 notebook on CPU, why tokens[:-1] matters for training, solved exercises (punctuation, unknown counting, save/load), and one small book correction.

This is part of my study series on the book "Build Your First LLM: A Hands-On Guide to Language Models" by Hasan Degismez. All slides, narration and diagrams are my own teaching adaptation. Please support the author and buy the book: https://leanpub.com/FirstLLM/
