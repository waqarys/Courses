## Description

Better outputs without touching the weights: the completion mindset, system messages, temperature and top-p, zero-shot, few-shot and chain-of-thought, delimiters, JSON output, prompt injection and systematic evaluation. I recompute the book's temperature table (at T=2 'purple' is 14%, not 20%) and run the chapter's prompts on a real Llama 3.2 3B: on the 7-case eval set the 'best' prompt scores 4/7 and obeys the adversarial review, while the simpler 'better' prompt scores 6/7 with lenient parsing. The scorer changes the ranking.
